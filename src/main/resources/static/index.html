🎯 Funcionalidades Principales

  • Escaneo de Códigos de Barras: Obtén información automática de productos
  • OCR Gratuito: Extrae fechas de caducidad automáticamente
  • Sistema de Alertas: Productos próximos a caducar
  • Sugerencias de Recetas: Ideas para usar productos antes de que caduquen

🛠️ Tecnologías Utilizadas (Todas Gratuitas)

  • Java 21 - Lenguaje de programación
  • Spring Boot 3.2.5 - Framework principal
  • H2 (en memoria) - Base de datos para desarrollo y pruebas
  • Tesseract OCR - Reconocimiento óptico de caracteres (gratuito)
  • Open Food Facts API - Base de datos de productos (gratuita)

🚀 Cómo Probar la API

Ejemplo con curl:

# Escaneo completo (recomendado)
curl -X POST http://localhost:8081/productos/escanear-completo \
  -F "codigoBarras=1234567890123" \
  -F "imagenFecha=@fecha_caducidad.jpg"

# Obtener todos los productos
curl http://localhost:8081/productos

# Productos próximos a caducar
curl http://localhost:8081/productos/alertas
